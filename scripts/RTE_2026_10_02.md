# RTE - the shared rich-text editor (wave 5, 2026-10-02)

Branch `wt/rte` from `2e92c759b`. Nothing compiled (house rules); every file was parse-checked with
`rustfmt --check`. Progress file: `scripts/RTE.PROGRESS.md`.

## 1. What was built

ONE rich-text editor for AzNotes, AzMail's compose window and (wave 6) AzWriter, following
scripts/DEDUP_EDITORS_2026_10_02.md A2 (the proposed design) and its adoption order (steps a-e of
item 9; f = Writer and g = Tasks / Calendar / Contacts are wave 6).

### 1.1 The model - `layout/src/widgets/rich_text/` (new)

- `doc.rs`: the FFI model (`repr(C)`, vectors through `impl_vec!`): `RichTextDoc { blocks }`,
  `RichBlock { kind, runs, align, quote_depth }`, `RichRun { text, link, formats }`,
  `RichFormats` (bold, italic, underline, strike, code), `RichFormat`, `RichBlockKind` =
  Paragraph | Heading(u8) | Bullet(u8) | Numbered(u8) | Check(RichCheck) | Code(lang) | Rule |
  Image(RichImage) | PageBreak | Table(RichTable), `RichAlign`, `RichTable` / `RichTableRow`
  (plain-string cells). The union of the three editors: AzNotes' five formats, nine kinds, nested
  lists and check items; AzWriter's alignment, page breaks and tables; AzMail's quote depth
  (DECISION: a quote is a per-block `quote_depth`, not a kind - Notes' `> ` shortcut and Quote
  button set depth 0 <-> 1, Mail's nested reply quotes are depth 2, 3, ...).
  The edits are AzNotes' (`doc.rs` promoted): `sync_block_text` (typing continues the format on
  the LEFT, a typing style wins), `split_block`, `merge_into_previous`, `replace_blocks` /
  `replace_with` (cross-block delete / paste), `set_kind` / `toggle_kind`, `apply_shortcut`,
  `set_format` / `toggle_format` (toggles OFF when all on), `has_format` / `formats_at`,
  `set_link` / `link_at` / `link_range_at` / `insert_run`, `indent`, `toggle_check`,
  `set_quote_depth`, `set_align`, `set_table_cell`, `insert_after`, `remove_block`, `normalize`,
  `plain_text`, `word_count`, `preview`, `checklist*`, `image_srcs`, `number_of`, `is_blank`.
  The run helpers (`flatten`, `push_run`, `normalize_runs`, `floor_char_boundary`, `isolate`,
  `split_runs`, `slice_runs`, `text_diff`) are ONE copy (AzNotes doc.rs and AzWriter ir.rs had
  twins, DEDUP_EDITORS A1). Markdown shortcuts: `shortcut_in` / `typed_shortcut`.
- `markdown.rs`: AzNotes' canonical writer (escaping, `<u>`, growing fences, nested list
  indents) and pulldown-cmark reader on the shared model, plus quotes per level (`> > `), GFM
  pipe tables, page breaks as `<!-- pagebreak -->`. `RichTextDoc::to_markdown` /
  `from_markdown` (reader behind feature `rich_text_markdown`).
- `html.rs`: AzMail's `to_html` / `to_plain` widened to every block kind (nested `<ul>`/`<ol>`,
  headings, code, tables, alignment, check marks, `<s>`, `<code>`), `from_plain_text` (`>` marks
  as depth), `from_html` through the ENGINE's paste sanitizer (`paste_html::sanitize_html`, one
  policy) and `blocks_from_doms` - the one DOM collector, also used for the engine's structural
  edit content (it reads the editor's own classes off cloned blocks and runs).
- `history.rs`: `RichTextHistory`, the ONE undo stack (snapshots; typing in one block is one
  step).

### 1.2 The widget - `layout/src/widgets/rich_text_editor.rs` (new)

- `RichTextEditorState` (the app keeps it: doc, history, host id, caret, revision, typing style)
  and `RichTextEditor` (builder: id, accessibility name, images, on_change, on_link, font size,
  paragraph spacing, built-in toolbar groups `RichTextToolbar`, Markdown shortcuts, read-only,
  theme). `dom()` = a themed frame (toolbar strip + page; `themes::flat::rich_text_editor` /
  `flora::rich_text_editor`, appended under `// ==== rich_text_editor ====`) around the host;
  `content_dom()` = the host alone (prints, apps with their own paper).
- Rendering: AzNotes' (one element per block, one node per run, check box as an island after the
  runs), with quote bars, alignment, page breaks (`Dom::create_page_break`), tables, images the
  app resolved (`with_image(src, ImageRef)`). Content colours are the mode's system colours.
- Engine glue (AzNotes' editor.rs on the shared state): `TextChanged` -> typing folded into
  runs; `DocumentEdit` -> split / merge / replace / paste mirrored and acked WITHOUT an inverse;
  `VirtualKeyDown` -> Ctrl/Cmd+B / I / U over a selection, Ctrl/Cmd+Shift+X, +E, +0..3,
  +Shift+7/8/9, +Enter, Enter in code / on an empty list item / on an empty quoted line,
  Backspace at a list item's / heading's / code block's / quoted line's start, Tab in a list,
  Enter / Backspace / Delete at a table cell's edge stopped. Check box clicks, Ctrl/Cmd+click on
  links (`on_link` or the system handler).
- App API: `apply_command(info, RichTextCommand)` (ribbons and toolbars), `sync(info)`,
  `get_selection(info)` + `set_link_on(info, spans, url)` (a link sheet that takes the focus),
  `replace_doc(info, doc)` (one undoable step), `set_doc`, `focus(info)`, `current_formats` /
  `current_kind` / `is_current_kind` / `is_current_format` / `is_current_quoted` (pressed
  buttons), `can_undo` / `can_redo`.
- Manifest: `rich_text_editor` in `every_widget_dom` (CONTAINERS group); tests in the file.

### 1.3 The bugs, fixed in the shared editor (DEDUP_EDITORS ids)

- A3.1 AzMail's `sync_text` flattened a paragraph to one text node (bold / links lost): the
  shared sync diffs the block text into its runs. Tests: `doc.rs`
  `typing_into_a_formatted_paragraph_keeps_its_bold_and_its_link`; RED integration test
  `layout/tests/a_rich_text_editor_keeps_one_model_and_one_history.rs`
  `typing_into_a_paragraph_with_bold_and_a_link_keeps_both_in_the_editors_model`.
- A3.3 Ctrl/Cmd+B / I / U over a selection did nothing in Mail / Writer: the editor's own key
  handler formats the model and cancels the engine default. RED test
  `ctrl_or_cmd_b_over_a_selection_makes_it_bold_in_the_model_and_cancels_the_engines_default`.
- A3.4 Mail's Bold twice nested `<b><b>`: `toggle_format` clears when all is on. Tests
  `bold_pressed_twice_over_a_selection_is_plain_again` (doc.rs) and
  `bold_pressed_twice_over_a_selection_leaves_it_plain` (RED).
- A3.6 / F2 Writer's two undo stacks: ONE history (the widget's); structural edits acked without
  an inverse; undo / redo reset the engine's per-host state (`reset_editor_content` drops the
  engine's text undo and structural history). RED tests
  `enter_is_acked_without_an_engine_side_inverse_and_the_editors_undo_takes_it_back`,
  `an_undo_of_a_format_puts_the_typing_and_the_format_back_one_step_at_a_time`.
- F3 Mail's reopened drafts lost their formats: `compose::draft_body` reads the HTML part
  (`RichTextDoc::from_html`). Test (AzMail) `a_reopened_draft_keeps_its_bold_its_link_and_its_quote`.
- F1 AzNotes dropped structural edits it could not mirror: the DOM collector reads pasted /
  cloned blocks (classes, `<b>`/`<i>`/`<u>`/`<s>`/`<code>`/`<a href>`, quotes, lists, tables,
  rules, page breaks) - a multi-block paste keeps kinds, formats, links and quote depth.

### 1.4 Adoption

- AzNotes (`examples/azul-notes`): `doc.rs` deleted (1399 lines), `editor.rs` 1078 -> ~190 lines
  (glue: state_for, editor_dom, print_dom, on_change -> note, run, sync, link, focus);
  `markdown.rs` keeps the front matter, the body is `RichTextDoc::from_markdown` / `to_markdown`;
  the toolbar runs `RichTextCommand`s (B / I / U now show pressed); the link sheet keeps the
  selection; the PDF export / the history's version view are read-only `content_dom`s; imported
  pictures are one undoable `replace_doc`; `pulldown-cmark` dependency removed. E2E: the first
  block is `#note-body-0` (blocks are `<host id>-<index>`; `scripts/aznotes_e2e.py` updated).
- AzMail compose (`examples/azul-mail`): `editor.rs` deleted (719 lines; the Dom-as-model and its
  class-smuggled hrefs), `compose.rs`'s MailDoc model and writers deleted (they live in
  `rich_text::html` now, with their tests); `reply_quote` / `forward_quote` / `draft_body` /
  `html_part` build on `RichTextDoc`; `ui_compose.rs` holds a `RichTextEditorState` per compose,
  `on_compose_body_change` keeps it, the ribbon runs commands and shows pressed states, Insert
  Link keeps the selection when its field opens. `#compose-body` stays the host id.
