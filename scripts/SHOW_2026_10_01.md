## What was built

### 1. Reusable widgets in azul (`layout/src/widgets/`, flat + flora, light + dark, tests, manifest)

Neither existed (AzPaint draws strokes on a GL/CPU image; AzWriter has no object canvas or slide rail).

- **`SelectionAdorner`** (`selection_adorner.rs`): the editing layer of any canvas of objects (slides,
  pages, drawings). The app hands it every object's frame (x, y, w, h, rotation in canvas units, z-order,
  selected) and the view's scale; it hit-tests those frames itself (turned frames included), draws the
  selection frame, eight resize handles and the rotate handle (percent-placed so they turn with the frame),
  the box around a multi-selection, four edges around the object whose text is being edited (no box over
  it, so its caret clicks reach the text: azul has no `pointer-events`), the snap guides and the marquee
  the app hands back. One callback, `SelectionAdornerEvent` (canvas units): Select (Shift adds, Ctrl
  toggles), Clear, Transform (move: Shift on one axis, snapped to the canvas edges / centre lines and the
  other objects' edges / centres with guides; resize from the opposite side along a turned frame's own
  axes, Shift keeps a corner's ratio, no flip, unrotated edges snap; rotate about the centre, Shift 15
  degree steps, a right-angle magnet), Commit, Marquee / MarqueeEnd (objects wholly inside), Activate
  (double-click, Enter, F2), Nudge (arrows, Ctrl fine), Delete, Escape, Tab / Shift+Tab walk the objects.
  A click on one object of a multi-selection selects it alone on release; a click slop of 3 px. Pointer
  callbacks on the root with pointer capture (the split pane's pattern), the drag state on the root's
  dataset with a merge callback so a drag survives the app's rebuild between moves. One named keyboard
  stop (role Diagram, value "n of m objects selected").
  Looks: flat = PowerPoint 2013 (grey hairline frame, white square handles, orange-red guides, pale blue
  marquee, field ring); flora = the accent stone (round paper handles, accent rotate dot, clay guides).
- **`ThumbnailStrip`** (`thumbnail_strip.rs`): the slide rail (column: number beside the preview) and the
  slide sorter (wrapping grid: number under it) in one widget; previews are the app's Dom in a clipped
  `thumb_width x thumb_height` box; badges; hidden items dimmed; section headers that fold their run of
  items (announced Collapsed / Expanded). One callback, `ThumbnailStripEvent`: Select (click / arrows,
  Shift / Ctrl), Activate (double-click / Enter), Move (drag and drop through the engine's DnD:
  `draggable`, DragStart sets the index under `application/x-azul-thumbnail`, DragOver accepts a move,
  Drop reports; or Ctrl/Cmd + Up/Down), Delete, SectionToggled. APG listbox keyboard (one Tab stop, the
  active item; Up/Down, Left/Right in the grid, Home/End).
  Looks: flat = PowerPoint 2013 rail (grey frame turning orange, peach wash); flora = paper previews on
  the strip, the accent when selected.
- Both registered by APPENDING: `pub mod` at the end of the module list, a manifest entry at the end of
  `label_convention::every_widget_dom`, their names at the end of the CHROME contrast group; looks
  appended at the END of `themes/flat.rs` and `themes/flora.rs` under `// ==== selection_adorner ====` /
  `// ==== thumbnail_strip ====`. Each widget's look is merged per part with
  `theme_blocks::follow_props` for an unpinned widget (the shells' pattern), so the app's content is built
  once.

### 2. The app (`examples/azul-show`)

- **Shell and chrome**: S1 `DocumentShell` (title row = `Titlebar` under `WindowDecorations::NoTitle`;
  ribbon or backstage; navigation = the rail; document = the canvas over the notes; side pane = the format
  pane; status bar) inside a `ShellThemeScope` whose accent follows the deck's theme; follows the app
  theme (flat / flora) and the OS mode; VIEW > Window and File > Options switch both.
- **Ribbon** (`ribbon.rs`): FILE; HOME (clipboard; slides: new / reset / section / hide; the layout
  gallery; font B I U S, grow / shrink, colour; paragraph bullets / indent / align; drawing: six shapes,
  front / back / group, fills, outline; editing: select all, undo, redo); INSERT (new slide with a layout
  gallery, table, pictures, shapes, bar / line / pie chart placeholders, text box, video placeholder);
  DESIGN (theme gallery with live previews: Office + the five flora stones; colour variants; font
  schemes; 16:9 / 4:3; slide ground; apply to all); TRANSITIONS (none / fade / push / wipe, duration,
  apply to all); ANIMATIONS (appear, fade, fly in, zoom, pulse, spin, disappear, fade out, fly out; move
  earlier / later); SLIDE SHOW (from beginning / current, hide slide); VIEW (normal / sorter / outline /
  notes page, notes toggle, zoom in / out / fit, app theme, mode); contextual FORMAT tab for a selection
  (arrange, group / ungroup, shape styles). Toggles show the selection's state.
- **Backstage** (`backstage.rs`): Info (the file `show/<id>/deck.json`, saved or not), New (theme cards
  each showing a live title slide in that theme, variant, fonts, size, Create, the sample deck), Open
  (the decks under `show/`, empty state, refresh), Save, Export (PDF; the current slide as PNG), Close,
  Options on `ShellSettingsLayout` (app theme, mode, keyboard shortcuts, About with the data folder).
- **Normal view** (`views.rs`): the rail (`ThumbnailStrip`, live previews from the one renderer, build /
  transition badges, sections that fold, drag reorder); the canvas (the slide rendered at the view's scale
  - fit to window or a zoom - under the `SelectionAdorner`: select, multi-select, marquee, move, resize,
  rotate, snapping guides, nudge, z-order and group from the ribbon / FORMAT tab and Ctrl+G / Ctrl+Shift+G,
  Ctrl+D duplicate, cut / copy / paste); text boxes edited in place with the rich editor (double-click /
  Enter: the text host becomes contenteditable, gets the focus, the engine's typing is synced run by run,
  Enter / Backspace across paragraphs mirrored with the inverse for the engine's undo, B / I / U over the
  selection or as the typing style at a caret); the notes pane (`TextArea`); the format pane (X / Y / W /
  H / rotation fields, fill, text size, the slide's ground and transition, the animation pane in click
  order); the status bar (SLIDE n OF m, language, notes toggle, message, the four view buttons, zoom).
- **Slide sorter** (the grid `ThumbnailStrip`, drag reorder, double-click opens the slide), **outline**
  (a title field and a bullets field per slide; the number opens the slide), **notes page** (every slide
  over its notes).
- **Slide show** (`show.rs`): F5 / Shift+F5 / the ribbon; the main window goes full screen
  (`WindowFrame::Fullscreen`, `prevent_system_sleep`), black around the fitted slide; builds play to the
  step (entrance / emphasis / exit effects drawn by a 16 ms player timer), transitions play from the slide
  before (fade, push, wipe); click / Space / Right / Down / PageDown / N / Enter forward, Left / Up /
  Backspace / PageUp / P back, B / W black / white, Home, a number + Enter jumps, Esc ends; "End of slide
  show, click to exit.". **Presenter view in a second window** (`CallbackInfo::create_window`): current
  slide, next slide, notes in large text, elapsed timer, slide n of m, Previous / Next / Black / End
  Show, a strip to jump; it closes itself (a 500 ms timer) when the show is over. `--no-presenter` for
  headless runs.
- **Model** (`model.rs`, pure, serde): deck -> slides -> elements (text, shape: rect / rounded / oval /
  triangle / line / arrow, image, table, chart and video placeholders, group) with frames (x, y, w, h,
  rotation) on 1920 x 1080 (16:9) or 1440 x 1080 (4:3); seven layouts with role-tagged placeholders
  (re-applying a layout keeps content by role, a subtitle stands in for a body); z-order; groups (a
  group's new frame maps and turns its members); sections; hidden slides; notes; transitions; builds and
  the show stepper; theme = colour scheme + font scheme; `deck.json` (format + version checked). The
  editing session (`editor.rs`, pure): every command, undo / redo as deck snapshots (one step per drag).
- **Files** (`storage.rs`): `<data dir>/azul/show/<uuid>/deck.json` and `show/<uuid>/media/<name>`
  through azul-storage's `Drive` on a `LocalDrive` (S3 later: swap the drive), from an azul `Thread`
  (`run_job` is the whole thread body: save, load with pictures, list, store a picture, import a picked
  picture). `AZSHOW_DATA` overrides the root. Sample deck "Azlin Workspace" (10 slides, sections, a
  hidden slide, builds, transitions, shapes, a quote, notes on every slide) with `--sample` or File > New;
  otherwise an empty state.
- **PDF export** through azul's PDF path (`Pdf::from_dom_in_callback`, one 960 x 540 page per shown
  slide, rendered by the one renderer), saved with `FileDialog::save_bytes`; the current slide as a PNG
  (`take_screenshot_of_node` of the canvas).
- **Command line** (`args.rs`): `--screen normal|sorter|outline|notes|backstage-new|backstage-open|show`,
  `--theme flat|flora`, `--mode light|dark`, `--sample`, `--open <deck id>`, `--slide n`, `--size WxH`,
  `--shot <png>`, `--no-presenter`. stdout lines for scripts: `AZSHOW_READY`, `AZSHOW_DECK`,
  `AZSHOW_SLIDE`, `AZSHOW_SLIDES`, `AZSHOW_ORDER`, `AZSHOW_FRAME`, `AZSHOW_VIEW`, `AZSHOW_SHOW`,
  `AZSHOW_SHOW_ENDED`, `AZSHOW_SHOW_CLOSED`, `AZSHOW_SAVED`, `AZSHOW_OPENED`, `AZSHOW_LISTED`,
  `AZSHOW_EXPORTED`.
- **Rich text**: text boxes use AzWriter's rich text IR (`azwriter::ir`: `to_content_dom`, `set_run_text`
  / `sync_block_text`, `apply_operation`, `toggle_format_range`) through a path dependency on the
  `azwriter` lib - one rich text model for both apps, no copy (`text.rs` converts `TextBody` <-> IR,
  bullets and levels ride along by paragraph index).

## .pptx import (not tonight): what it needs

A .pptx is an OOXML zip. Read `ppt/presentation.xml` (slide list, `p:sldSz` cx/cy in EMU: 12192000 x
6858000 for 16:9 - one slide unit = cx / 1920 EMU), each `ppt/slides/slideN.xml` with its `_rels`:
`p:sp` shapes (`a:xfrm` off / ext / rot in 60000ths of a degree -> `Frame`; `a:prstGeom prst` rect /
roundRect / ellipse / triangle / line / rightArrow -> `ShapeKind`; `a:solidFill` / `a:ln`; `p:txBody`
paragraphs `a:p` / runs `a:r` with `a:rPr` b / i / u / strike / sz (hundredths of a point) / colour,
`a:pPr` algn / lvl, `a:buChar` / `a:buNone` -> `Paragraph`), `p:ph type=title|ctrTitle|subTitle|body idx`
-> `PlaceholderRole` (geometry inherited from `slideLayouts` / `slideMasters` when the slide has no
`a:xfrm`), `p:pic` with `r:embed` -> the rel -> `ppt/media/*` -> `show/<id>/media/`, `p:graphicFrame`
`a:tbl` -> `Table`, charts (`c:chart`) -> `Chart` placeholders, `p:grpSp` -> `Group` (child offsets
through `a:chOff` / `a:chExt`), `p:transition` (fade / push / wipe / dur) -> `Transition`, `p:timing`
build lists -> `Animation` order, `ppt/notesSlides/*` -> notes, `ppt/theme/theme1.xml` (`a:clrScheme`
dk1 / lt1 / accent1..3, `a:fontScheme` major / minor latin) -> `Theme`, sections from the `p14:sectionLst`
extension. Crates: `ppt-rs` where it suffices, `zip` (azul has a `zip` module) + `quick-xml` /
`roxmltree` (already in the tree) for the rest. View-only import first; round-trip export later
(decides how rich the element model must be - open question 2 of the plan).
