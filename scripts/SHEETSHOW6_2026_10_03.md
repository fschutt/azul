## Decisions
- LOOK runs were scripted (one bounded `run_capped` call each), not interactive: the machine-wide lock was shared.
- Merges (IronCalc): kept by the engine per worksheet `sheet_id` and written into a COPY of the model on save -
  IronCalc's UserModel cannot change `merge_cells`. So merges are not undo steps and do not shift when rows or
  columns are inserted / deleted.
- Format Cells' OK sends one style command per changed property (several undo steps, not one).
- The conditional format's looks are Excel's three presets; data bars / icon sets / colour scales from a loaded
  file colour the cell (IronCalc's extended style) but their bars and icons are not drawn.
- Find in AzShow matches run by run (a match across two differently formatted runs is not found) so a
  replacement keeps its run's format.
