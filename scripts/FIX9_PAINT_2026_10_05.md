### 2.1 CSS zoom -> border-radius / box-shadow (/ outline)
Commits: RED e633df1bd (getters inline), RED 3e446e777 (pixel file), GREEN e64b16ce8.
Root cause: LAYOUT7 zoomed the box model, but the paint lengths go to the renderer as declared (and the
compact fast path of `get_border_radius` decodes authored px): radius (both paths), the Border item's
`StyleBorderRadius` and widths, and shadow lengths were painted unzoomed. One helper `getters::PaintZoom`
(through `scale_length_for_zoom`): `get_border_radius` zooms both paths, `get_style_border_radius` and
`get_box_shadows` return zoomed lengths (paint-only getters), `paint_box_decorations` zooms the Border item's
widths (`get_border_info` stays declared: taffy_bridge uses it for layout, which zooms it itself).
azul has NO CSS `outline` property (grep: not parsed anywhere) - nothing to zoom; outline support is NOT SMALL.
RED: `css_zoom_scales_border_radius_and_box_shadows` (getters.rs autotest) and the pixel tests
`a_zoomed_border_is_painted_at_its_zoomed_width`, `a_zoomed_border_rounds_its_corners_at_the_zoomed_radius`,
`a_zoomed_box_casts_its_shadow_at_the_zoomed_offset` (Chrome: every length x2).
Verify: those 4 tests; the existing zoom tests (css_zoom_scales_the_lengths_of_its_subtree), box-shadow tests.

### 2.4 CPU SVG stroke linecap / linejoin / dasharray
Commits: RED 4c6e646a2, GREEN 03e377e56.
Root cause: `render_svg_group_inner` hard-coded Round/Round and never read the stroke properties. Now one
`SvgStrokeStyle::of(node, inherited)` (element first, then groups; defaults butt / miter / 4 / none / 0), the
inherited style carries the five properties, and a dash pattern wraps the path in `ConvDash` (offset folded
into one period). SVG `miter` = AGG `MiterRevert` (bevel past the limit), `miter-clip` = `Miter`. A negative /
unreadable / zero-period / >16-pair pattern strokes solid (AGG holds 32 lengths; a zero period would loop).
RED `an_svg_stroke_takes_its_linecap_linejoin_and_dasharray` (cpurender/svg.rs). Verify: it; the existing
degenerate-stroke tests (NaN/inf widths now fall back to the group's / 1.0 instead of reaching agg).
