  box / rename); moving it to ListView or DataTable now loses features (section 8).
- D7 The planned month lives on Scheduled ("List | Month"), the board on a list ("List | Board") - not new smart
  lists; the layout choice is not kept across restarts (in memory, like the folded "Completed").
- D8 Board columns: To do / Doing / Done from the task itself (Done = completed, Doing = `started`), no per-list
  column definitions (the plan's "sections"); `started` is a task-file field other versions ignore.
- D9 Tag suggestions are static per build of the pane (typing does not filter them: the tag field does not rebuild
  the pane while typing, as the quick-add line does not).
- D10 AzMeet reads the earlier visit's files only for a meeting server's room (the demo mints a new code each run);
  the earlier people are merged into the record, the join time is this visit's.
- D11 The shared E2E driver: a tap releases its modifiers (a chord is not held across ops); `App.name(stem)` is the
  prefix helper, a process label is `tag`.
