## Cross-cutting themes (from the ten reports)

1. **UA `<p>` margin (`margin: 1em 0`) leaking into widgets** — NumberInput/TextInput height, hello-world, TextArea placeholder offset, likely Button labels. One shared reset fixes several symptoms.
2. **Relayout fast paths that skip a step** — the macOS/X11 resize fast path never rebuilds the CPU hit-tester (stale clicks/wheel: scroll area, AzMap "+"); the layout path passes an empty selection map (selection flicker); dataset-only rebuilds never re-invoke the VirtualView; `NodeResized` is dead in production.
3. **No pointer capture** — events target whatever is under the pointer; MouseLeave bubbles (W3C: it does not) and still cuts the map pan / split-pane drag; releases outside the window never reach the pressed widget. Press-target capture is the structural fix.
4. **Two builders disagreeing** — patched display-list builds vs wholesale re-emission (TextArea jump); flex item sized standalone vs by its container.
5. **Transparent compositor layers + LCD text** — the first-draw ghosting; also the latent DPI-change-as-grow.
6. **Demos that drop state** — `on_switch`/`on_slider` ignoring the widget state and rebuilding; map hooks discarding `Update`s; zoom cap reached in one flick.
7. **Capture pipeline** — no requested size honoured on macOS, six full-resolution passes per frame.

Already fixed on this branch before these reports: the slider's drag/trail (dd90d4938, b44804467), wheel-glide ringing (51da00316 — NOT the trackpad overscroll), Windows/X11 button latch after native drags (91f0eb7a0; macOS `performWindowDragWithEvent:` is the uncovered twin).
