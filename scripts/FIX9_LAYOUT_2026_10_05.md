  text-indent only from the IFC root's OWN DOM node. An anonymous block has none, so it never added an
  indent at all (not "for every IFC") and measured itself as `white-space: normal`. The first anonymous
  block of `<div style="text-indent:40px">x<div>..</div>y</div>` was 40px too narrow, a `nowrap`

  `layout_ifc` had inline, now shared) and ONE first-line gate `fc::anonymous_block_holds_the_first_line`
  (64d3cb633's gate, now shared by `layout_ifc` and the intrinsic scan).
- Tests (sizing.rs `mod anonymous_ifc_intrinsic_tests`): `an_anonymous_block_that_starts_its_container_adds_the_indent_to_its_max_content`

- Root cause: `layout_ifc`'s `subtree_fingerprint` folded node fingerprints (own data + inline CSS), the
