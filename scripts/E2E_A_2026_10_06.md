## Per app

### AzCalculator
- Failure: "Escape closes the About box first: expected 'closed', last 'open'".
- Root cause (ENGINE, dll headless): the About box is a Modal = a `<transient-window>` popup,
  a `Menu`-type window. Headless `is_menu_window` counted it as a window-based menu, so the
  owner's Escape went to `dismiss_menu_windows`, which closed the popup silently (no Dismissed,
  no on_close) and spent the key. And headless `deliver_forwarded_keys` was the no-op default:
  a key forwarded to a keyboard-owning popup was never replayed.
- Commits: c0a7ef37f RED, 49d34f0b0 GREEN (`dll/src/desktop/shell2/headless/mod.rs`).
- Probe: the Escape sent to the modal's own window closes the box; the script then PASSES.

### AzCalendar
- editor ("AZCAL_EDITOR closed" never came) - ENGINE (layout): "Save & Close" half under the
  fold; the press on its label focuses the button, the focus scrolls it 12 px into view, the
  release lands on its padding, and the engine clicked only when press and release hit the SAME
  node. Fix: W3C - `click` goes to the nearest common ancestor (`HoverManager::
  apply_press_target_capture`, where the tree is known). 2c5292337 RED, e42a91049 GREEN.
- close - SCRIPT: "Don't Save" was clicked in the editor window; the question is a Modal, a
  window of its own (`reach_modal`, 7a26433ee). ENGINE: the CloseGuard's Discard calls
  `close_window()` inside the modal's popup, which closed the popup instead of the guarded
  window (the editor stayed open on "This appointment is closed.", and the next editor under the
  same window id was unreachable). Fix: a close asked from a popup closes its owner
  (`TransientWindowData::close_owner`, `transient::post_close_owner`, `SyncOutcome::close_owner`,
  `PlatformWindow::request_close_by_app`). 410c86966 RED, 94dc5c544 GREEN.
- contrast (9 findings, flora light) - ENGINE (debug server): gradients were dumped as
  `unknown` without bounds, so text on flora's gradients read as text on white. Fix:
  `linear_gradient` / `radial_gradient` / `conic_gradient` items with bounds and the mean of the
  stops (`gradient_item_info`). 0ac74f7ca RED, 2aa707695 GREEN; the script composites them
  (0fc182265).
- Probe: with a scroll_into_view before Save, import / editor / repeat / occurrence PASS.

  lingers in today's libazul (built before 30fb9f06b) and headless `dismiss_menu_windows` spent
